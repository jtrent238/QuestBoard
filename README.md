# QuestBoard
A website that turns your real life into an RPG game. You create quests for yourself, complete them, earn XP, level up, unlock achievements, and build streaks.



<img width="1400" height="1050" alt="image" src="https://github.com/user-attachments/assets/22634d5b-ed29-4759-9e8f-053c2de722ef" />


## How it works
- Your real-life tasks become quests.
- Real-life task	Quest reward
- Clean your room	+50 XP
- Do 30 minutes of exercise	+100 XP
- Finish homework	+75 XP
- Read 20 pages	+40 XP
- Work on a project for 1 hour	+150 XP

## Features
- Quest system — create daily, weekly, and custom quests.
- XP & levels — earn XP and progress through levels.
- Streaks — reward consecutive days of completing quests.
- Achievements — unlock badges for milestones.
- Skill tree — upgrade categories like Fitness, Intelligence, Creativity, and Discipline.
- Boss battles — big goals broken into milestones.
- Inventory — collect virtual items and rewards.
- Leaderboard — compete with friends.
- Avatar — customize your character as you level up.
